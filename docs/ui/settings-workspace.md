# Settings → Workspace

## How do I export workspace data?

The Owner or an Admin goes to **Settings → Workspace → Export**. The export arrives as a ZIP with JSON and original files. The download link is valid for **7 days**. Only one export per workspace can run at a time.

## Can I change a workspace's region?

No. The region is chosen when the workspace is created and cannot be changed. To move, export the data and create a new workspace in the other region.

## Which regions can I pick when creating a workspace?

| Region code | Location | Shown on |
|-------------|----------|----------|
| `us-east` | Virginia, USA | All plans (default) |
| `eu-central` | Frankfurt, Germany | Business and Enterprise |
| `ap-south` | Mumbai, India | Enterprise only |

## How many workspaces can I create?

Free and Starter **1**, Pro **3**, Business **10**, Enterprise unlimited.
